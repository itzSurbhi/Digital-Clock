# ⏰ Digital Clock

A simple and stylish Digital Clock built using **HTML, CSS, and JavaScript**. The clock displays the current time in real-time and updates every second.

## 🚀 Features

* Real-time clock display
* Updates automatically every second
* Modern neon-glow UI design
* Responsive and lightweight
* Built with pure HTML, CSS, and JavaScript

## 📸 Preview

The clock displays the current system time in the following format:

```text
10:45:32 PM
```

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript


## ⚙️ How It Works

1. JavaScript creates a new `Date` object every second.
2. The current time is extracted using `toLocaleTimeString()`.
3. The time is displayed inside the clock container.
4. `setInterval()` updates the display every 1000 milliseconds (1 second).


## 🎯 Learning Outcomes

* Working with JavaScript Date Object
* DOM Manipulation
* Using setInterval()
* Creating responsive UI with CSS
* Real-time data updates in web applications.
